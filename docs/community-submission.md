## English

The following procedure records the initial submission; the plugin is already published.

Submission uses the [Obsidian Community portal](https://community.obsidian.md), rather than a pull request to `obsidianmd/obsidian-releases`. Follow the [official submission guide](https://docs.obsidian.md/plugins/releasing/submit-plugin).

Before submitting, ensure the public repository's default branch contains the current README, LICENSE, and manifest. The release tag must match the version in `manifest.json` and include `main.js` and `manifest.json` as assets; this plugin needs no stylesheet.

1. Sign in to the portal with an Obsidian account.
2. On the community profile, use **GitHub → Connect** to authorize the GitHub account that owns this repository.
3. Open **Plugins → New plugin**. Enter the repository URL above and choose **Myself** as Owner.
4. The owner must personally read and accept the developer policies and confirm continued support, or removal/transfer if support ends. Then select **Submit**.

Account and form details are covered in [Set up and claim](https://docs.obsidian.md/community-directory/set-up-and-claim).

Review the automated scan. Fix reported errors in the repository and publish an incremented release. Resolve errors before publishing the listing; publishing a GitHub release alone does not add the plugin to Obsidian's catalog. See [Manage your plugin or theme](https://docs.obsidian.md/community-directory/manage-entry).

## Español

El siguiente procedimiento documenta el envío inicial; el plugin ya está publicado.

El envío se realiza en el [portal Obsidian Community](https://community.obsidian.md), sin abrir un pull request en `obsidianmd/obsidian-releases`. Sigue la [guía oficial de envío](https://docs.obsidian.md/plugins/releasing/submit-plugin).

Antes del envío, comprueba que la rama predeterminada del repositorio público contiene el README, LICENSE y manifest actuales. La etiqueta de versión debe coincidir con la versión de `manifest.json` y adjuntar `main.js` y `manifest.json`; este plugin no necesita hoja de estilos.

1. Inicia sesión en el portal con una cuenta de Obsidian.
2. En el perfil, usa **GitHub → Connect** para autorizar la cuenta de GitHub propietaria del repositorio.
3. Abre **Plugins → New plugin**. Introduce la URL de arriba y selecciona **Myself** en Owner.
4. El propietario debe leer y aceptar personalmente las políticas y confirmar que mantendrá el soporte o retirará/transferirá el plugin si deja de mantenerlo. Después, selecciona **Submit**.

La configuración de la cuenta y los campos aparecen en [Set up and claim](https://docs.obsidian.md/community-directory/set-up-and-claim).

Revisa el análisis automático. Corrige los errores en el repositorio y publica otra versión incrementada. Resuelve los errores antes de publicar la ficha; una versión en GitHub no incorpora por sí sola el plugin al catálogo. Consulta [Manage your plugin or theme](https://docs.obsidian.md/community-directory/manage-entry).
